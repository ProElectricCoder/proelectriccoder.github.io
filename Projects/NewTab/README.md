# Ampere

A fast, customisable new tab page for Chrome, by [ProElectricCoder](https://proelectriccoder.pages.dev/Projects/NewTab/).

- Live clock and date, gradient or picture backgrounds, light/dark themes
- Search bar with many search engines (and your own), shortcuts grid
- News: developer news, suggestions, and optional world headlines
- Weather card
- **Add-ons**: optional extras that are downloaded only when you press *Install*
- Safe, staged updates, and a one-file backup of your settings

## Install

Ampere is an unpacked Chrome extension (it is not on the Chrome Web Store yet).

1. Open the [download page](https://proelectriccoder.pages.dev/Projects/NewTab/) and download the files into a folder, or use *Link folder* to let it write them for you.
2. In Chrome open `chrome://extensions`, switch on **Developer mode**, press **Load unpacked** and choose that folder.
3. Open a new tab.

To get updates, open **Settings → Auto-Updates** in Ampere and link the same folder.

## Add-ons

Open **Settings → Add-ons**. Pressing **Install** downloads the add-on into an `addons/` folder inside your extension folder, checks it, and saves it. Nothing is downloaded for add-ons you never install, and **Remove** deletes the file again.

| Add-on | What it does |
| --- | --- |
| Prayer Times | Daily prayer times, next prayer countdown, Hijri date |
| Notes, To-do & Focus | Sticky notes you can pin to the page, tasks, focus timer |
| Planner | Daily, weekly and monthly planner with repeating items |
| Break Reminder | Eye-rest and stretch reminders |
| Extra Themes | Eighteen colour presets |
| Exam Master | Step-by-step picker (Cambridge, OxfordAQA, Edexcel, AQA, OCR) that opens a search for the exact exam paper |
| GitHub Activity | A public GitHub profile's recent activity and repositories |
| Wallpapers | Daily background from NASA APOD, Wikipedia, Art Institute of Chicago, Picsum or Unsplash |

Add-ons run with the same permissions as the extension itself, so only install add-ons you trust. Every add-on in this repository is reviewed by hand before it is accepted.

## Your data

Shortcuts, settings, notes and plans are stored **in your browser** and never uploaded. Some features contact other websites to work (for example weather, prayer times, news, and website icons from Google's favicon service); each is explained in Settings next to its switch. Settings → Backup exports everything, add-on data included, to one file.
